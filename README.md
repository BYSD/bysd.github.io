## 🚀 Getting Started

### **Prerequisites**
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML, CSS, and JavaScript
- GitHub account for deployment

### **Local Development**
1. Clone the repository:
   ```bash
   git clone https://github.com/bysd/bysd.github.io.git
   cd bysd.github.io
   ```

2. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

3. Open `http://localhost:8000` in your browser

### **Deployment to GitHub Pages**
1. Push your code to GitHub:
   ```bash
   git add .
   git commit -m "Initial portfolio website"
   git push origin main
   ```

2. Enable GitHub Pages in your repository settings
3. Your site will be available at `https://yourusername.github.io`

## 🎨 Customization

### **Colors & Themes**
The website uses CSS custom properties for easy theming:

```css
:root {
    --primary-color: #00d4ff;      /* Main accent color */
    --accent-color: #ff4081;       /* Secondary accent */
    --bg-primary: #0a0a0a;         /* Background color */
    --text-primary: #ffffff;       /* Primary text */
    --text-secondary: #b0b0b0;     /* Secondary text */
}
```

### **Content Updates**
- **Personal Information**: Update `index.html` with your details
- **Skills**: Modify skill percentages in HTML and CSS
- **Projects**: Add/remove portfolio items
- **Contact**: Update contact information and social links

### **Styling Changes**
- **Animations**: Modify CSS keyframes for different effects
- **Layout**: Adjust CSS Grid and Flexbox properties
- **Typography**: Change fonts in CSS and HTML head
